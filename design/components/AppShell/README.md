# AppShell

The proposed desktop layout, read left to right the way CapCut is: **rail → gallery → stage → inspector**, with the source strip along the bottom like a timeline.

- Top bar (52px, `panel`): logo + project name, undo / redo, at most three status chips, settings gear, then the only two big actions — บันทึก and ไลฟ์ — at the far right.
- Stage: PVW left, PGM right, both 16:9 with their tally ring; transition controls centred under them. The stage gets all leftover width.
- Gallery (300px) follows the rail's category; Inspector (`inspector-width`) follows the selection.
- Tablet: gallery collapses into a sheet opened from the rail. Phone: rail becomes the bottom tab bar, stage on top, source strip as a horizontal scroller, inspector as a bottom sheet.
