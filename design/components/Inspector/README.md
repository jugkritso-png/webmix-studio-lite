# Inspector

The right panel (`inspector-width` 300px) that edits whatever is selected — a source, a graphic, a destination — the CapCut contextual-panel pattern. Nothing selected: it shows the program output's settings.

- Header: the item's name in `title` and its tally chip. Tabs (`amber` underline, shipped `.tab`) group properties; at most four.
- Show the three to five controls people use most; everything else sits behind **ตั้งค่าขั้นสูง** (progressive disclosure, as Settings already does with พื้นฐาน / ขั้นสูง).
- Changes apply live and are undoable; there is no Save button inside the inspector.
