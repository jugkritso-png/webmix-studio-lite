# SegmentedControl

Two to five mutually exclusive options on a `well` ground (shipped `.seg`). The selected segment lifts to `panel-3` with `text`; the rest are `muted`.

- Provide: short labels (one word), `aria-pressed` on each button.
- Use for modes that change the view instantly (MIX / WIPE / STINGER, 16:9 / 9:16, พื้นฐาน / ขั้นสูง). More than five options: a select.
- Text is 12px/600 (was 11px/700).
