# AssetTile

A thumbnail in the gallery (`radius-xl`, `panel-2`). The round **+** (`accent`, 28px) adds it in one tap; dragging the tile onto a monitor or into the source strip does the same. A badge in `tag` names the type (NDI, SRT, MP4).

- Provide: thumbnail, name (`caption` 12px/600, one line), type badge.
- The first tile of every category is the dashed "new" tile that opens the add dialog for that category.
- Selected: `accent-line` border. Hover: `line-strong` border.
