# TransitionKeys

The two big keys under the monitors (shipped `.key`): **CUT** on `pgm-fill` with `on-accent` text, **AUTO** on `amber` with `on-amber` text (white on amber is 2.0:1). Type is `key` (15px/800, .12em). Each key shows its shortcut beneath the word in `tag`.

- Provide: the transition name and duration on AUTO ("MIX 0.5s"), chosen with the SegmentedControl beside it.
- Always `control-key` (54px) tall, also on phones; nothing else in the app is this big.
- Don't: add more keys in this row; put FTB / stinger in the inspector instead.
