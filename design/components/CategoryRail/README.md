# CategoryRail

The left column (`rail-width` 72px, on `panel`) that picks what the gallery shows — the CapCut pattern of one vertical list of media types instead of many tabs. Seven fixed categories in this order: แหล่งภาพ, เสียง, กราฟิก, ข้อความ, คอมเมนต์, เอฟเฟกต์, ไลฟ์.

- Each item is a 22px stroke icon over a `caption` label; never icon-only. Current item: `accent-soft` ground, `text` label, `accent-text` icon.
- On phones the rail becomes the bottom tab bar with the same order and labels (44px targets).
- Settings is not a category: it lives behind the gear in the top bar.
