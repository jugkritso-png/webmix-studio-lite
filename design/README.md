WebMix คือสวิตเชอร์ไลฟ์ที่คนทั่วไปใช้ได้ทันที ทั้งบนเว็บ เดสก์ท็อป และ Android ระบบนี้คงสีและตัวอักษรเดิมของแอป แล้วจัดโครงหน้าจอและพฤติกรรมใหม่ตามแนวทางของแอปตัดต่อสมัยใหม่อย่าง CapCut: ภาพพรีวิวเป็นพระเอก เลือกหมวดทางซ้าย หยิบของจากแกลเลอรี แล้วปรับรายละเอียดในแผงขวา

## หลักการออกแบบ

1. **พรีวิวคือพระเอก** ให้พื้นที่ที่เหลือทั้งหมดกับจอ PVW / PGM (`AppShell`) ปุ่มและแผงต่าง ๆ ใช้พื้น `panel` เรียบ ๆ ไม่แย่งสายตา
2. **หมวด → แกลเลอรี → ตัวปรับ** ทุกอย่างที่เพิ่มเข้าโชว์ได้เริ่มที่ `CategoryRail` (แหล่งภาพ, เสียง, กราฟิก, ข้อความ, คอมเมนต์, เอฟเฟกต์, ไลฟ์) แล้วเลือกจาก `AssetTile` ส่วนการปรับค่าทำใน `Inspector` ของสิ่งที่เลือกอยู่เท่านั้น
3. **แตะเดียวก็เพิ่มได้** ทุกไทล์มีปุ่ม + สี `accent` และลากไปวางบนจอหรือแถบแหล่งภาพได้ ไม่ต้องผ่านไดอะล็อก
4. **เปิดเผยทีละชั้น** แสดงแค่ 3–5 ค่าที่ใช้บ่อย ที่เหลือซ่อนหลัง "ตั้งค่าขั้นสูง" เหมือนหน้าตั้งค่า พื้นฐาน / ขั้นสูง ที่มีอยู่
5. **สีเดียวสำหรับการกระทำ** ใช้ `accent` เท่านั้นกับสิ่งที่กดได้และสิ่งที่ถูกเลือก แดง (`pgm`) และเขียว (`pvw`) สงวนไว้บอกสถานะ tally ห้ามใช้เป็นสีปุ่ม
6. **ย้อนกลับได้เสมอ** ทำทันทีแล้วให้ `Toast` มีปุ่ม "ย้อนกลับ" แทนการถามยืนยัน ยกเว้นการหยุดไลฟ์
7. **ปุ่มใหญ่มีแค่สองปุ่ม** "บันทึก" และ "ไลฟ์" อยู่มุมขวาบนเสมอ บนมือถืออยู่ในแถบล่าง

## ภาษาและน้ำเสียง

- เขียนภาษาไทยสั้น ขึ้นต้นด้วยกริยา: "เพิ่มแหล่งภาพ", "เริ่มไลฟ์", "เชื่อมต่อ YouTube"
- คำเฉพาะของวงการเขียนเป็นอังกฤษตัวพิมพ์ใหญ่: PGM, PVW, CUT, AUTO, NDI, OMT, SRT, RTMP ชื่อแพลตฟอร์มเขียนตามแบรนด์ (YouTube, Facebook)
- พูดกับผู้ใช้ตรง ๆ ไม่ใช้ "ท่าน" ไม่ใช้อีโมจิ ไม่ใช้เครื่องหมายตกใจ
- ข้อความผิดพลาดบอกวิธีแก้ เช่น "ใส่ URL ที่ขึ้นต้นด้วย rtmp:// หรือ srt://" ไม่ใช่ "รูปแบบไม่ถูกต้อง"
- ตัวเลขที่เปลี่ยนตลอด (เวลาไลฟ์, บิตเรต, CPU) ใช้สไตล์ `timecode` ฟอนต์ mono เพื่อไม่ให้กระตุก

## สี

| ใช้กับ | โทเคน |
|---|---|
| พื้นแอป | `bg` |
| แผง (rail, แกลเลอรี, inspector, แถบบน) | `panel` |
| แถวยกขึ้น, ส่วนท้ายการ์ด, toast | `panel-2` |
| สิ่งที่ถูกเลือก / กดค้าง | `panel-3` |
| พื้นช่องกรอก, segmented | `well` |
| ข้อความหลัก / รอง / ลำดับสาม | `text` / `muted` / `dim-aa` |
| ปุ่มหลัก, สไลเดอร์, สวิตช์เปิด | `accent` + ตัวอักษร `on-accent` |
| วงโฟกัส, ขอบที่ถูกเลือก | `accent-line` |
| ลิงก์ | `accent-text` |
| กำลังออกอากาศ | ขอบ `pgm` + `glow-pgm`, ป้าย `pgm-fill` |
| เตรียมออกอากาศ | ขอบ `pvw` + `glow-pvw`, ป้าย `pvw-fill` |
| AUTO, แท็บที่เลือก, คำเตือน | `amber` + ตัวอักษร `on-amber` |

- ข้อความบน `pgm-fill`, `pvw-fill` และ `accent` ใช้ `on-accent` (ขาว) ข้อความบน `amber` ใช้ `on-amber` เท่านั้น เพราะขาวบนอำพันได้แค่ 2.0:1
- `dim` ของเดิมได้ 3.16:1 บน `panel` ซึ่งต่ำกว่าเกณฑ์ ใช้ได้แค่ข้อความที่ปิดใช้งาน ข้อความที่ต้องอ่านให้ใช้ `dim-aa`
- `line` และ `line-2` เป็นเส้นตกแต่ง (ต่ำกว่า 3:1) ทุกสถานะต้องมีการเปลี่ยนพื้นหรือ `accent-line` ร่วมด้วย ห้ามบอกสถานะด้วยเส้นขอบอย่างเดียว
- สถานะ tally บอกเป็นคำเสมอ (PGM / PVW / LIVE) ไม่ใช่สีอย่างเดียว คนตาบอดสีแดง-เขียวต้องแยกได้
- ไม่ใช้ไล่เฉดสีบนปุ่มอีกต่อไป ปุ่มทุกแบบเป็นสีพื้นเรียบ

## ตัวอักษร

- ใช้ `--font-sans` (Inter สำหรับละติน, IBM Plex Sans Thai สำหรับไทย) และ `--font-mono` (JetBrains Mono) จาก Google Fonts
- ขั้นตัวอักษร: `display` 28 → `title` 16 → `body` 14 → `label` 13 → `caption` 12 ห้ามเล็กกว่า 12px สำหรับภาษาไทย (ของเดิมมี 9–10.5px บนการ์ดและป้ายช่องกรอก ให้ยกขึ้นเป็น `caption`)
- `tag` 11px mono ใช้ได้กับป้ายละตินสั้น ๆ เท่านั้น (PGM, PVW, เลข 1–9, NDI)
- `key` ใช้กับปุ่ม CUT / AUTO เท่านั้น

## ระยะ ขนาด และมุมโค้ง

- ระยะห่างใช้ `space-1` 4 · `space-2` 8 · `space-3` 12 · `space-4` 16 · `space-6` 24 · `space-8` 32 เท่านั้น
- ความสูงปุ่ม: `control-sm` 28 ในแถบเครื่องมือ, `control-md` 34 บนเดสก์ท็อป, `control-lg` 44 บนอุปกรณ์สัมผัสทุกชนิด, `control-key` 54 สำหรับ CUT / AUTO
- มุมโค้ง: `radius-xs` ปุ่มย่อยและจอ, `radius-sm` ปุ่มและช่องกรอก, `radius-md` แผงและ toast, `radius-lg` การ์ดแหล่งภาพ, `radius-xl` ไทล์ในแกลเลอรี, `radius-pill` ชิปเท่านั้น
- เงา: `glow-pgm` / `glow-pvw` หมายถึง tally เท่านั้น สิ่งที่ลอย (เมนู, toast, ของที่กำลังลาก) ใช้ `pop`

## สถานะและโฟกัส

- โฟกัสคีย์บอร์ดทุกตัวใช้ `focus-ring` (ช่อง `bg` 2px แล้ววง `accent-line` 2px ได้ 5.6:1 บน `bg`)
- Hover: พื้นขยับขึ้นหนึ่งขั้น (`panel-2` → `panel-3`) และขอบเป็น `line-strong`
- เลือกอยู่: `accent-soft` พื้น + `accent-text` ไอคอน (rail) หรือขอบ `accent-line` (ไทล์)
- ปิดใช้งาน: ตัวอักษร `dim` บน `panel`
- ทุกการกระทำที่ทำลายข้อมูล → ทำทันที + `Toast` "ย้อนกลับ" 5 วินาที

## เลย์เอาต์

- เดสก์ท็อป: แถบบน 52px / `CategoryRail` `rail-width` / แกลเลอรี 300px / เวที (จอ PVW + PGM + ปุ่มเปลี่ยนภาพ) / `Inspector` `inspector-width` / แถบการ์ดแหล่งภาพด้านล่าง ดู `AppShell`
- แท็บเล็ต: แกลเลอรีกลายเป็นแผ่นที่เลื่อนออกจาก rail
- มือถือ: rail กลายเป็นแถบแท็บล่างลำดับเดิม, จออยู่บน, การ์ดเลื่อนแนวนอน, inspector เป็น bottom sheet

## ไอคอน

- ไอคอนเส้น 24px, เส้นหนา 1.75, ปลายมน, `stroke="currentColor"` ใช้ขนาด 18px ในปุ่มและ 22px ใน rail
- โค้ดเดิมแทบไม่มีชุดไอคอน ชุดใน `CategoryRail` และ `AppShell` เป็นชุดที่เสนอใหม่ วาดขึ้นสำหรับระบบนี้ ห้ามใช้อีโมจิแทนไอคอน
- โลโก้คือ `assets/Logos/webmix-mark.svg` (สี่เหลี่ยมมุมโค้งสี `pgm` มีวงกลม `bg` ตรงกลาง) วางคู่กับคำว่า WebMix ใน `title`

## ส่วนที่เพิ่มใหม่โดยตั้งใจ

`CategoryRail`, `AssetTile`, `Inspector`, `StatusChip`, `Toast` และ `AppShell` ยังไม่มีในแอปปัจจุบันในรูปนี้ เพิ่มเพื่อยกโครง rail → แกลเลอรี → inspector ของ CapCut มาใช้ โทเคนที่ขึ้นต้นคำอธิบายว่า PROPOSED (`pgm-fill`, `pvw-fill`, `dim-aa`, `line-strong`) เป็นค่าที่เสนอเพื่อให้ผ่านเกณฑ์ความคมชัด ค่าอื่นทั้งหมดตรงกับ `assets/app.css`
